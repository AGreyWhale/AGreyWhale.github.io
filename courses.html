    • ▸ 📄 computer_organization.circ ✦ done
      toolLogisim isaY86-64 pipeline5-stage

      Designed and implemented a fully functional processor capable of executing programs written in the Y86-64 instruction set architecture — a teaching ISA closely modeled on 64-bit x86. Built from scratch in Logisim, with each processing block — fetch, decode, control, ALU, registers, and data memory — developed and verified independently before integration into a five-stage pipeline. This is the CPU design project featured on the Projects page.

      Project Details
      • Designed a scaled-down ISA and verified each functional stage (instruction fetch, decoder, control unit, ALU, register file, data memory read/write, and full datapath).
      • Implemented ROM-to-RAM boot loading: program instructions and initial matrix data were loaded into ROM, then copied to RAM at simulation start.
      • Demonstrated the processor running at least 3 Y86-64 programs covering all supported instructions, including a 2×2 matrix addition stored in and read from RAM.
      • Generated a full processor timing diagram (via WaveDrom) showing icode, ifun, rA, rB, valC, valP, valA, valB, valE, valM, and the new PC at each pipeline stage output.
      • Modularized the Logisim circuit using sub-circuits to clearly demarcate each component for readability and grading clarity.
